Job Overview

Amazon is hiring a Data Engineer I in Bengaluru for the Data Platform and Analytics team. The role builds modern data infrastructure, real-time processing systems, AWS-native pipelines and governed data products that support analytics and AI/ML workloads.

Eligibility

Bachelor's degree plus 1+ years of data engineering experience. Amazon lists SQL, data modeling, data warehousing, ETL pipeline development, a query language such as SQL or SparkSQL, and a scripting language such as Python as basic qualifications.

Skills Mentioned

SQLData modeling and warehousingETL pipelinesPython or another scripting languageAWS data servicesBig data technologies

Key Responsibilities

  • 1Build modern data infrastructure for real-time analytics and AI/ML workloads
  • 2Develop reliable data pipelines for analysts, data scientists and downstream consumers
  • 3Manage AWS resources such as S3, Redshift, EMR, Lambda and EC2
  • 4Implement data quality, metadata and governance capabilities
  • 5Support event-driven and change-data-capture architectures
  • 6Deliver data products with clear reliability and quality expectations

Who Should Apply?

Candidates with a bachelor's degree and at least one year of data engineering experience who have worked with SQL, ETL and scripting are aligned with the basic qualifications.
