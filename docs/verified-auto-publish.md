HD Careers — Verified auto-publishing Phase 1

Existing 9 AM discovery/official-source precheck is retained. The new workflow is scheduled 11:30 AM IST and additionally responds to final ranking commits. It auto-selects at most ten newly discovered Fresher IT, Fresher Non-IT, internship or apprenticeship roles with exact employer-source ACTIVE confirmation less than 18 hours old. Unsure/expired/errors and roles already published or under review are not selected.

The existing Admin Direct Publish pipeline rechecks each official application URL before adding it to data/jobs.json, generating public pages, and enqueueing Telegram hourly messages. When recheck is inconclusive, an automated selection is held rather than added to the owner's manual queue. A batch is claimed in data/auto-publish-ledger.json BEFORE dispatch to avoid duplicates; failed dispatch claims require manual reconciliation. Existing manual VIP/Admin publishing and expiry safeguards remain unchanged.

The 7K WhatsApp Channel is NOT auto-posted. WhatsApp Business messaging and WhatsApp Channel publishing are different services; this phase does not rely on unauthorized browser bots. Telegram post links and website links are available for a manual mirror while an approved Channel publishing method is evaluated.

Run the GitHub workflow verified-auto-publish.yml manually or commit data/auto-publish-kick.json with the message 'Trigger verified auto-publish...' to initiate an exact-source check for today's batch.
